# NextBschool 🎓🚀
> **AI-Powered Education Portal for MBA Aspirants in India**

NextBschool is a next-generation MBA & PGDM discovery and decision platform designed to empower aspirants across India with authentic placement data, real fee breakdowns, AI-driven profile evaluation, and side-by-side b-school comparisons.

---

## 🌟 Key Features

### 1. 🏛️ Comprehensive 10-City B-School Directory
Curated directory of premier MBA/PGDM institutes across **10 key Indian hubs**:
- **Delhi NCR** (FMS Delhi, MDI Gurgaon, IIFT, DMS IIT Delhi, IMT Ghaziabad, FORE, LBSIM, BIMTECH)
- **Mumbai** (SPJIMR, JBIMS, IIM Mumbai, SJMSOM IIT Bombay, NMIMS, SIMSREE, K J Somaiya)
- **Bangalore** (IIM Bangalore, SIBM Bengaluru, JAGSoM, XIME)
- **Pune** (SIBM Pune, SCMHRD, PUMBA Pune)
- **Chennai** (Great Lakes Chennai, DoMS IIT Madras, LIBA)
- **Kolkata** (IIM Calcutta, VGSoM IIT Kharagpur, IMI Kolkata)
- **Ahmedabad** (IIM Ahmedabad, MICA, Nirma University IMNU)
- **Jaipur** (Jaipuria Jaipur, TAPMI School of Business MUJ, IIHMR Jaipur)
- **Chandigarh** (UBS Panjab University, LM Thapar School of Management)
- **Dehradun** (School of Business UPES, Doon Business School DBS)

### 2. 🤖 AI Profile Predictor (`/predictor`)
Calculates an aspirant's admission probability (High, Moderate, Dream) based on:
- CAT / XAT / NMAT percentiles
- Class 10th, 12th & Graduation marks
- Work experience & category

### 3. ⚖️ 3-Way B-School Comparator (`/compare`)
Compare up to three colleges side-by-side on:
- Highest, average, and median CTC
- Tuition & hostel fees
- Category-wise exam cutoffs
- Batch size & NIRF rank
- Top hiring sectors & recruiters

### 4. 💬 B-Bot AI Admissions Counselor (`/counselor`)
Interactive conversational advisor that helps students navigate:
- Exam strategies (CAT vs XAT vs NMAT)
- GD-WAT-PI preparation tactics
- ROI evaluations & scholarships

### 5. 💰 MBA ROI Calculator (`/roi-calculator`)
Calculates net return on investment, opportunity cost, and payback period in months.

### 6. 📅 National MBA Exam Hub (`/exams`)
Deadlines, eligibility, pattern, and registration links for CAT, XAT, SNAP, NMAT, and CMAT.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Architecture**: Modular components, client-side caching & REST APIs

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm or yarn

### Installation
```bash
git clone https://github.com/financeview2-cpu/nextbschool.git
cd nextbschool
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build
```bash
npm run build
npm run start
```
